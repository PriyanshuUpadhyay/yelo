**Goal:** Instant, durable worker→orchestrator signaling between herdr panes via a rename-based (Maildir-shaped) file bus — no daemon, no sockets.

**Architecture:** One bus dir per herdr workspace. Writers publish by writing a complete JSON file into `tmp/` and atomically `rename()`ing it into `events/`; delivery state is per-subscriber consumed-marker dirs (`unread = events − markers`), never a timestamp watermark — publication order and consumption are independent, so a slow writer can never be skipped. A TTL-bounded `watch` subcommand is the chair's doorbell: run as a harness background task, it exits when an unconsumed event exists (or TTL), which re-invokes the chair. The bus carries signals only; `agent-handoff.py verify` stays the completion truth.

**Tech Stack:** Python 3 stdlib only (`os`, `json`, `select.kqueue` with poll fallback). macOS/APFS primary; POSIX rename atomicity is the load-bearing primitive.

## Global Constraints

- Python 3 stdlib only; no new dependencies, no daemon, no sockets.
- All bus writes go through `tmp-write → rename` on the same filesystem; nothing ever appends to or edits a file inside `events/`. No fsync anywhere: the bus promises process-crash atomicity, not power-loss durability — signals are re-derivable from agent-handoff artifacts, which are the durable truth (deliberate decision, council change #2).
- Event filename grammar is the wire protocol: `<ns19>.<from>.<kind>.<u8>.json` — 19-digit zero-padded ns timestamp (ordering hint only, never a delivery predicate), `from`/`kind` sanitized to `[a-z0-9-]{1,32}`, 8-hex uniquifier. One `time.time_ns()` call feeds both the name and the body `ts`.
- Delivery predicate is set difference: `events/` listing minus `cursors/<subscriber>.d/` marker names. Markers are created AFTER the event is emitted to stdout, so a crash mid-scan redelivers rather than loses.
- Bus dir: `$HERDR_BUS_DIR` if set, else `~/.local/state/herdr/bus/$HERDR_WORKSPACE_ID` (error if neither). Chair-side, `HERDR_BUS_DIR` is REQUIRED to be injected as a fully-expanded literal into every worker context (cross-workspace/worktree spawns otherwise resolve a different bus dir and emit into a directory nobody watches). `emit` prints its resolved bus root to stderr so a misroute is visible in the pane.
- Payload ≤ 4KB; larger content goes to a side file, event carries its path in `ref`.
- Every `watch` exit path — including argument/config errors — prints exactly one final stdout JSON line `{"reason","cursor_at_wake","new","via"}`.
- No event-kind filtering anywhere (`--kinds` cut per council change #4): one unfiltered signal stream; a `blocked` event must wake the chair as fast as a `done`.
- File: `~/dotfiles/home/.claude/scripts/herdr-bus.py` (symlinked live as `~/.claude/scripts/herdr-bus.py`). Tests: `~/dotfiles/home/.claude/scripts/tests/test_herdr_bus.py`, stdlib `unittest`.

```python
#!/usr/bin/env python3
"""Session-bound pane pub/sub over a rename-based file bus. Signaling only:
completion truth stays with agent-handoff.py verify. Delivery is set
difference (events minus per-subscriber markers), never a cursor watermark,
so publication order and consumption order are independent."""
import argparse, json, os, re, sys, time, uuid

IDENT = re.compile(r"^[a-z0-9-]{1,32}$")
NAME = re.compile(r"^(\d{19})\.([a-z0-9-]{1,32})\.([a-z0-9-]{1,32})\.([0-9a-f]{8})\.json$")

def bus_dirs():
    root = os.environ.get("HERDR_BUS_DIR")
    if not root:
        ws = os.environ.get("HERDR_WORKSPACE_ID")
        if not ws:
            sys.exit("herdr-bus: set HERDR_BUS_DIR or HERDR_WORKSPACE_ID")
        root = os.path.expanduser(f"~/.local/state/herdr/bus/{ws}")
    d = {k: os.path.join(root, k) for k in ("tmp", "events", "cursors", "watch")}
    for p in d.values():
        os.makedirs(p, exist_ok=True)
    return {"root": root, **d}

def sanitize(value):
    out = re.sub(r"[^a-z0-9-]", "-", (value or "").lower())[:32].strip("-")
    if not IDENT.match(out):
        sys.exit(f"herdr-bus: unusable identifier {value!r}")
    return out

def emit(from_, kind, ref=None, data=None):
    d = bus_dirs()
    ts = time.time_ns()
    body = json.dumps({"ts": ts, "from": from_, "kind": kind,
                       "ref": ref, "data": data}, separators=(",", ":"))
    if len(body) > 4096:
        sys.exit("herdr-bus: payload over 4KB — write a side file and pass --ref")
    name = f"{ts:019d}.{from_}.{kind}.{uuid.uuid4().hex[:8]}.json"
    tmp = os.path.join(d["tmp"], name)
    with open(tmp, "w") as fh:
        fh.write(body)
    # No fsync: rename atomicity gives process-crash safety; power-loss
    # durability is deliberately not promised (artifacts are the durable truth).
    os.rename(tmp, os.path.join(d["events"], name))
    print(f"herdr-bus: root={d['root']}", file=sys.stderr)
    return name

def marker_dir(d, sub):
    p = os.path.join(d["cursors"], sub + ".d")
    os.makedirs(p, exist_ok=True)
    return p

def unread(d, sub):
    events = {n for n in os.listdir(d["events"]) if NAME.match(n)}
    return sorted(events - set(os.listdir(marker_dir(d, sub))))

def mark(d, sub, name):
    # Markers follow the bus-wide tmp→rename protocol (user ruling 2026-08-03):
    # a leftover .tmp.<pid> from a crash is inert — it matches no event name.
    p = os.path.join(marker_dir(d, sub), name)
    tmp = p + f".tmp.{os.getpid()}"
    open(tmp, "w").close()
    os.rename(tmp, p)

def scan(sub, consume=False, out=sys.stdout):
    d = bus_dirs()
    delivered = []
    for name in unread(d, sub):
        with open(os.path.join(d["events"], name)) as fh:
            body = json.loads(fh.read())
        body["name"] = name
        out.write(json.dumps(body, separators=(",", ":")) + "\n")
        out.flush()
        if consume:
            mark(d, sub, name)  # after output: crash here redelivers, never loses
        delivered.append(name)
    return delivered

def main():
    ap = argparse.ArgumentParser(prog="herdr-bus")
    sub = ap.add_subparsers(dest="cmd", required=True)
    e = sub.add_parser("emit")
    e.add_argument("--from", dest="from_", required=True)
    e.add_argument("--kind", required=True)
    e.add_argument("--ref")
    e.add_argument("--data")
    s = sub.add_parser("scan")
    s.add_argument("--subscriber", required=True)
    s.add_argument("--consume", action="store_true")
    a = ap.parse_args()
    if a.cmd == "emit":
        data = json.loads(a.data) if a.data else None
        print(emit(sanitize(a.from_), sanitize(a.kind), a.ref, data))
    elif a.cmd == "scan":
        scan(sanitize(a.subscriber), a.consume)

if __name__ == "__main__":
    main()
```

Every watch exit path removes its own lease, pid-guarded (unlink only when the lease's pid is our own), so an exited watcher's fresh lease can never suppress the replacement watcher (final-review P1); a SIGKILLed watcher's surviving lease is caught by doctor's `lease_alive` probe instead.

```python
def write_lease(d, sub, ttl):
    path = os.path.join(d["watch"], sub + ".lease")
    tmp = path + f".tmp.{os.getpid()}"
    with open(tmp, "w") as fh:
        json.dump({"pid": os.getpid(), "ttl_s": ttl}, fh)
    os.rename(tmp, path)
    return path

def finish(code, reason, n_unread, new, via):
    print(json.dumps({"reason": reason, "cursor_at_wake": n_unread,
                      "new": new, "via": via}))
    sys.exit(code)

def watch(sub, ttl, tick):
    via = "poll"
    try:
        d = bus_dirs()
    except SystemExit as err:
        print(json.dumps({"reason": "error", "cursor_at_wake": None,
                          "new": [], "via": via, "detail": str(err)}))
        raise
    lease_path = write_lease(d, sub, ttl)
    kq = ev = None
    try:
        import select
        kq = select.kqueue()
        dfd = os.open(d["events"], os.O_RDONLY)
        ev = select.kevent(dfd, filter=select.KQ_FILTER_VNODE,
                           flags=select.KQ_EV_ADD | select.KQ_EV_CLEAR,
                           fflags=select.KQ_NOTE_WRITE)
        kq.control([ev], 0, 0)  # register BEFORE the first scan (arm-then-scan)
        via = "kqueue"
    except (ImportError, AttributeError, OSError):
        kq = None
    deadline = time.monotonic() + ttl
    while True:
        new = unread(d, sub)
        if new:
            finish(0, "event", len(new), new, via)
        if time.monotonic() >= deadline:
            finish(2, "ttl", 0, [], via)
        os.utime(lease_path)  # heartbeat: metadata-only, never an append
        remaining = max(0.05, min(tick, deadline - time.monotonic()))
        if kq:
            kq.control(None, 1, remaining)
        else:
            time.sleep(remaining)
```

```python
def doctor(gc):
    d = bus_dirs()
    now = time.time()
    events = [n for n in os.listdir(d["events"]) if NAME.match(n)]
    report = {"lease_age_s": {}, "lease_ttl_s": {}, "unread": {},
              "tmp_orphans": 0, "events": len(events), "gc_events": 0}
    for f in os.listdir(d["watch"]):
        if f.endswith(".lease"):
            p = os.path.join(d["watch"], f)
            report["lease_age_s"][f[:-6]] = round(now - os.stat(p).st_mtime, 1)
            try:
                report["lease_ttl_s"][f[:-6]] = json.load(open(p)).get("ttl_s")
            except (json.JSONDecodeError, OSError):
                report["lease_ttl_s"][f[:-6]] = None
    subs = [f[:-2] for f in os.listdir(d["cursors"]) if f.endswith(".d")]
    for s in subs:
        report["unread"][s] = len(unread(d, s))
    for f in os.listdir(d["tmp"]):
        p = os.path.join(d["tmp"], f)
        if now - os.stat(p).st_mtime > 3600:
            report["tmp_orphans"] += 1
            if gc:
                os.unlink(p)
    for n in events:
        p = os.path.join(d["events"], n)
        if now - os.stat(p).st_mtime > 7 * 86400:
            report["gc_events"] += 1
            if gc:
                os.unlink(p)
                for s in subs:
                    try:
                        os.unlink(os.path.join(marker_dir(d, s), n))
                    except FileNotFoundError:
                        pass
    print(json.dumps(report))
```

```python
def emitter(busdir, idx, count):
    env = {**os.environ, "HERDR_BUS_DIR": busdir}
```

## Rejected / deferred (ADHD review + council)

- **Epoch fencing & `--kinds`** (council change #4): cut as overbuilt for a trusted single-chair session. Fencing turned every watcher replacement into a burned chair turn (each exit re-invokes); kind-filtering could delay a `blocked` wake by up to TTL. Duplicate watchers are harmless (non-consuming) and suppressed before arming via the doctor lease check.
- **Nest unification** (artifact-as-signal): overlaps `agent-handoff.py`'s publish/verify contract; revisit only if the two-layer design shows drift in practice.
- **Expectation stubs, `_health` topic for all panes, overlapping jittered-TTL watchers, claim-based reviewer auto-dispatch**: additive on this grammar later; not needed for v1's failure case.
- **Hostile-pane defenses** (CAS cursors, symlink guards): wrong threat model — trusted single-user session.
- **Power-loss durability**: deliberately not promised; signals are re-derivable from artifacts. (Council: the previous file-fsync-without-dir-fsync was a half-measure — removed entirely.)

## Residual risk (accepted, from council)

The doorbell's liveness depends on the chair following the arming rule — prose, not structure. Mitigations: doctor-lease-check as the first action of every wake (visible in the same output the chair already reads), TTL as deadman so a lapse costs at most one TTL, and the ledger Observable tracking missed-completion incidents.
